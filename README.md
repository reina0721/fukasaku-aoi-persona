# 深作葵 · Fukasaku Aoi Persona

基于《COPPELION》动画版的分层角色蒸馏包，包含研究证据、人物种子、DSH适配器与离线验证。

完整说明和产物入口见 [README-aoi.md](README-aoi.md)。

首次克隆请同时获取固定版本的上游依赖：

```sh
git clone --recurse-submodules git@github.com:reina0721/fukasaku-aoi-persona.git
cd fukasaku-aoi-persona
node test-aoi.mjs
```

已有克隆可运行 `git submodule update --init --recursive`。
